# Security policy

## Reporting a vulnerability

Report it privately through
[GitHub's report form](https://github.com/akshad-exe/signalless-android/security/advisories/new). Do not open a public issue.

Include the affected version, steps to reproduce and the impact. Use synthetic
data: no real messages, keys, peer IDs, locations or unredacted logs.

This is a volunteer project with no promised response time.

## Supported versions

Only the [latest release](https://github.com/akshad-exe/signalless-android/releases/latest) receives fixes.

## Know the limits

SignalLess has not had an independent security audit, and this fork has not been
validated on physical devices. Do not rely on it where a failure could put someone
at risk.
